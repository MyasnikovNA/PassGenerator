# PassGenerator

A simple password generator for Windows, built with Rust and egui.

## Features

- Generate random passwords
- Customize password length and characters
- Copy passwords to clipboard

## Download

A ready-to-use Windows `.exe` is available in GitHub Releases.

Download the latest `PasswordGenerator.exe` here:

https://github.com/MyasnikovNA/PassGenerator/releases/latest

No installation required.

## Build from source

git clone https://github.com/MyasnikovNA/PassGenerator.git
cd PassGenerator
cargo run --release
